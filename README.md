# AFRO & CO. (Afro.co) — Luxury E-Commerce Platform

A modern luxury e-commerce web platform built with React 19, TypeScript, Vite, and Tailwind CSS.

- **[GoDaddy Shared Hosting & Store Customization Guide](./GODADDY_HOSTING_AND_CUSTOMIZATION_GUIDE.md)**:
  - Step-by-step GoDaddy cPanel / `public_html` deployment.
  - Apache `.htaccess` SPA routing configuration (included in `public/.htaccess`).
  - How to change site name, logos, and SEO meta tags.
  - How to customize color themes and typography.
  - Admin management for products, discounts, orders, categories, and currencies.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production / GoDaddy Deployment
```bash
npm run build
```
Upload all files inside the `dist/` folder directly to your GoDaddy `public_html/` folder.
